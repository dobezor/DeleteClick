DeleteClick - Удаление элементов с сайта

Расширение позволяет удалять элементы с веб-страницы с помощью правой кнопки мыши.

Функциональные возможности:

  • Удаление элементов: Удалите любые элементы страницы с помощью правой кнопки мыши.
  • Режим выделения: Выделяйте элементы на странице для их удаления с помощью кликов.
