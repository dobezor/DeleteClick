DeleteClick

Удаляйте элементы с веб-страниц с помощью правой кнопки мыши

Что такое DeleteClick?

DeleteClick — это расширение для браузера, которое позволяет удалять элементы с веб-страниц с помощью правой кнопки мыши. Вы можете быстро удалять ненужные элементы с сайта, такие как объявления, блоки рекламы или любые другие компоненты страницы.

Основные функции

  • Удаление элементов: Используйте правую кнопку мыши для удаления элементов с веб-страницы.
  • Режим выделения: Выделите элементы на странице для их быстрого удаления.
  • Настройки: Включите или выключите удаление и режим выделения через настройки расширения.

Как установить?

Чтобы установить расширение, выполните следующие шаги:

  1. Перейдите в Chrome Web Store (или магазин вашего браузера).
  2. Найдите расширение DeleteClick.
  3. Нажмите кнопку "Добавить в Chrome".
  4. После установки и активации вы сможете использовать все функции расширения.
